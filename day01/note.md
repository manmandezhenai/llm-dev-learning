# Day1：环境搭建 & 基础语法

## 一、环境搭建

### 1. Python 安装

- 官网地址：https://www.python.org/downloads/
- 安装时：务必勾选「Add Python 3.11 to PATH」
- 验证安装：打开命令提示符（`CMD`），输入 `python --version`，输出版本号即为安装成功

### 2. PyCharm 安装与配置

- 官网地址：https://www.jetbrains.com/pycharm/download/
- 版本选择：社区版（Community）
- **解释器配置**：新建项目时选择「New environment using Virtualenv」，自动创建项目独立虚拟环境，避免依赖冲突

### 3. 常用快捷键

| 快捷键              | 功能          |
|------------------|-------------|
| `Shift + F10`    | 运行当前脚本      |
| `Shift + F9`     | 调试模式运行      |
| `F8`             | 单步执行（调试时）   |
| `Ctrl + /`       | 单行注释 / 取消注释 |
| `Ctrl + Alt + L` | 自动格式化代码     |
| `点击行号左侧`         | 添加 / 取消断点   |

## 二、基础语法

### 1. 变量与命名规范

- 变量无需声明类型，直接赋值即可，Python 为动态类型语言
- 赋值语法：`变量名 = 值`
- 命名规则：
    - 只能由字母、数字、下划线组成
    - 不能以数字开头
    - 区分大小写
    - 不能使用 Python 关键字（如 `if`、`for`、`True` 等）
    - 推荐：见名知意，小写字母 + 下划线命名法（如 `user_name`）

### 2. 四大基础数据类型

| 类型      | 说明                         | 示例                  |
|---------|----------------------------|---------------------|
| `int`   | 整数                         | `age = 22`          |
| `float` | 浮点数（小数）                    | `score = 92.5`      |
| `str`   | 字符串，单 / 双引号均可              | `name = "张三"`       |
| `bool`  | 布尔值，仅 `True` / `False` 两个值 | `is_student = True` |

### 3. 输入与输出

#### 输出函数 `print()`

- 基础用法：`print(内容)`
- 多参数输出：`print(内容1, 内容2, sep="分隔符", end="结尾符")`
    - `sep`：多个参数之间的分隔符（默认为空格）
    - `end`：输出结尾的字符（默认为 `\n`）

#### 输入函数 `input()`

- 基础用法：`变量名 = input("提示文字")`
- 注意：`input()` 返回的永远是字符串类型，需要数字时必须强制类型转换
    - `int(x)`：将 x 转整数
    - `float(x)`：将 x 转浮点数

## 三、PyCharm 断点调试入门

1. **设置断点**：点击代码行号左侧空白处，出现红点即为断点
2. **调试运行**：按 `Shift + F9` 进入调试模式，程序会运行到断点处暂停
3. **单步执行**：按 `F8` 逐行执行代码，可在下方 Debug 窗口查看当前所有变量的值
4. **适用场景**：排查逻辑错误、查看变量中间值、定位 Bug

## 四、今日踩坑记录

1. 坑：运行代码提示「No Python interpreter configured」
    - 解决：`File → Settings → Project → Python Interpreter` 中选择对应虚拟环境

2. 坑：`input()` 输入数字后运算报错
    - 解决：`input` 返回字符串，必须用 `int()` / `float()` 强制转换
