## 一、条件判断

### 1. 核心语法

Python 通过缩进区分代码块（推荐 4 个空格），条件成立才执行缩进内的代码。

```python
if 条件1:
    条件1成立执行
elif 条件2:
    条件2成立执行
else:
    所有条件都不成立执行
```

### 2. 关键要点

- 多分支判断时，从上到下匹配，命中一个后不再执行后续分支
- 比较运算符：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于）
- 逻辑运算符：`and`（与）、`or`（或）、`not`（非）
- 三元表达式（简化双分支）：`结果 = 值 if 条件 else 值2`

## 二、循环结构

### 1. for 循环（遍历循环）

- 适用场景：遍历序列、固定次数循环
- 核心搭配 `range()` 函数：
    - `range(n)`：生成 `0` 到 `n - 1` 的整数序列
    - `range(start, end)`：生成 `start` 到 `end - 1` 的整数
    - `range(start, end, step)`：按步长 `step` 生成序列
- 遍历可迭代对象：`for item in 列表 / 字典 / 字符串:`

### 2. while 循环（条件循环）

- 适用场景：循环次数不固定，满足条件就持续执行
- 语法：`while 条件:` 条件为 `True` 就反复执行循环体
- 注意：必须设置退出条件，否则会造成死循环

### 3. 循环控制语句

| 语句         | 作用                       |
|------------|--------------------------|
| `break`    | 立刻跳出**整个循环**，不再执行后续循环    |
| `continue` | 跳过**本次循环**，直接进入下一次循环     |
| `else 子句`  | 循环正常结束（没被 `break` 打断）时执行 |

## 三、函数基础

### 1. 函数定义与调用

- 定义语法：

```python
def 函数名(参数列表):
    """函数文档字符串，说明功能"""
    函数体代码
    return 返回值
```

- 调用：`函数名(参数)`
- 函数必须先定义后调用

### 2. 参数分类

| 参数类型 | 说明          | 规则                                                  |
|------|-------------|-----------------------------------------------------|
| 必选参数 | 调用时必须传入的参数  | 数量、顺序必须匹配                                           |
| 默认参数 | 调用时可省略，有默认值 | 必须放在必选参数后面                                          |
| 返回值  | 函数执行完返回的结果  | 用 `return` 返回；不写 `return` 默认返回 `None`；可返回多个值（本质是元组） |

### 3. 函数设计原则

- 单一职责：一个函数只做一件事
- 输入输出清晰：通过参数接收数据，通过 `return` 返回结果
- 避免在函数内部修改全局变量

## 四、今日踩坑记录

1. 坑：`IndentationError` 缩进错误
    - 解决：同一代码块缩进必须一致，统一使用 4 个空格，不要混淆 Tab 和空格

2. 坑：`while` 循环忘记更新条件变量，导致死循环
    - 解决：循环体内必须修改判断条件，或设置 `break` 退出

3. 坑：默认参数放在必选参数前面，语法报错
    - 解决：默认参数必须写在参数列表最后
