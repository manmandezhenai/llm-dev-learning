# Day2：核心数据结构

## 一、列表（List）

### 1. 核心特性

- 有序、可变的元素序列，支持存放不同数据类型的元素
- 使用方括号 `[]` 定义，元素之间用逗号分隔
- 索引从 `0` 开始，支持负索引（`-1` 表示最后一个元素）

### 2. 高频方法

| 方法             | 功能说明                      |
|----------------|---------------------------|
| `append(x)`    | 在列表末尾添加元素 x               |
| `insert(i, x)` | 在索引 i 位置插入元素 x            |
| `remove(x)`    | 删除第一个匹配的元素 x              |
| `pop(i)`       | 删除并返回索引 i 的元素（默认删除最后一个）   |
| `index(x)`     | 返回元素 x 第一次出现的索引           |
| `sort()`       | 原地排序，`reverse = True` 为降序 |
| `reverse()`    | 原地反转列表                    |
| `len(list)`    | 返回列表元素个数                  |

### 3. 切片操作

- 语法：`列表[start:end:step]`，左闭右开区间
    - `start`：起始索引（省略默认为 `0`）
    - `end`：结束索引（省略默认为序列末尾）
    - `step`：步长（省略默认为 `1`）

## 二、字典（Dict）

### 1. 核心特性

- 键值对（`key-value`）存储结构，通过 `key` 快速查找 `value`
- 使用花括号 `{}` 定义，键与值用冒号分隔
- `key` 必须唯一且不可变（字符串、数字、元组），`value` 可以是任意类型
- Python 3.7+ 版本默认保留插入顺序

### 2. 高频方法

| 方法                  | 功能说明                   |
|---------------------|------------------------|
| `dict[key] = value` | 添加或修改键值对               |
| `get(key, 默认值)`     | 获取 key 对应值，不存在返回默认值    |
| `keys()`            | 返回所有键                  |
| `values()`          | 返回所有值                  |
| `items()`           | 返回所有键值对                |
| `pop(key)`          | 删除指定 key 的键值对并返回 value |
| `update(dict2)`     | 合并另一个字典的键值对            |

---

## 三、元组（Tuple）

### 1. 核心特性

- 有序、不可变的元素序列，创建后无法增删改
- 使用圆括号 `()` 定义，单个元素必须加逗号：`(10,)`

### 2. 常用操作

- 支持索引、切片、`len()`、`count()`、`index()`
- 元组解包：`name, age = ("张三", 20)`
- 适用场景：固定常量集合、函数多返回值

---

## 四、集合（Set）

### 1. 核心特性

- 无序、元素唯一的集合，自动去重
- 使用花括号 `{}` 定义，**空集合必须用 `set()` 创建**（`{}` 是空字典）
- 核心用途：数据去重、集合运算（交、并、差）

### 2. 高频方法

| 方法                   | 功能说明          |
|----------------------|---------------|
| `add(x)`             | 添加元素 x        |
| `remove(x)`          | 删除元素 x，不存在则报错 |
| `union(set2)`        | 返回两个集合的并集     |
| `intersection(set2)` | 返回两个集合的交集     |
| `difference(set2)`   | 返回两个集合的差集     |

## 五、今日踩坑记录

1. 坑：用 `{}` 创建空集合，实际变成了空字典
    - 解决：空集合必须用 `set()` 初始化

2. 坑：列表索引超出范围报 `IndexError`
    - 解决：访问前先判断长度，或优先用负索引从末尾取值

3. 坑：字典 `key` 不存在直接访问报 `KeyError`
    - 解决：优先使用 `get()` 方法并设置默认值
